# Aspen Plus-Validated Design and Techno-Economic Evaluation of a Honeyed Bitter-Kola (Garcinia kola) Tablet Manufacturing Plant

## Overview

This repository contains the full manuscript for an Aspen Plus-validated pharmaceutical process design and techno-economic evaluation of a honeyed bitter-kola (Garcinia kola Heckel) tablet manufacturing facility developed for Nigerian operating conditions.

The work integrates:
- Aspen Plus V14-equivalent solids-process simulation
- Pharmaceutical process engineering
- Techno-economic analysis (TEA)
- HAZOP-based process safety assessment
- GMP-oriented phytopharmaceutical manufacturing design
- Environmental and sustainability evaluation

---

## Abstract

A 50 kg h⁻¹ honeyed bitter-kola tablet manufacturing facility was designed and validated using Aspen Plus-equivalent steady-state solids simulation. Eight pharmaceutical unit operations — hammer crushing, pin milling, tray pre-drying, V-cone blending, high-shear wet granulation, oscillating size reduction, fluid-bed drying, and rotary tablet compression — were rigorously modelled under strict component and mass-balance constraints.

The validated process achieved:
- 53.89 kg h⁻¹ finished-tablet throughput
- ~776 million tablets annually
- 90.4 wt% overall process yield
- 41.7% internal rate of return (IRR)
- 3-year discounted payback period

The study demonstrates the technical feasibility, regulatory compliance, process safety, and economic viability of industrial-scale Garcinia kola phytopharmaceutical manufacturing in West Africa.
